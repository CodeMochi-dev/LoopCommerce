# LoopCommerce - E-Commerce Simulator (Consola en Java)

## Descripción breve del desafío
LoopCommerce es un simulador básico de e-commerce en consola desarrollado en Java.  
Permite registrar y visualizar productos y clientes, aplicando conceptos básicos de programación orientada a objetos y estructuras de repetición.

## Tecnologías usadas
- Java 21
- Scanner
- Loops (`for`, `foreach`, `while`, `do-while`)
